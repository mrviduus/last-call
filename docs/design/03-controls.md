# Controls

**Status:** Current. Keyboard only.

## Basic

| Input | Action |
|---|---|
| WASD | Walk: A/D left and right, W/S into and out of the screen |
| A A / D D (double tap) | Run |
| J | Punch: jab, then a straight from the back hand (the one-two). The 3rd punch in a row that lands is a **Smash** (high kick) |
| L | Kick. **L-L-L**: at the knee, into the body, then a spinning roundhouse that knocks flying. **J-J-L**: a sweep that drops them on the spot |
| K or Space | Jump |
| J + K together | **Special**: a spinning kick all round. It costs health, which you win back by landing hits |
| J + L together | **Dirty move** on whoever is right in front: a knee to the groin for a guy, a hair slam for a girl. No grab needed. Not on THE CLOSER. Works again after 3 s |
| S + L | Hammer stomp: drives the enemy into the floor |
| H (hold) | Show the controls |
| M | Sound on / off (remembered; the HUD shows SOUND OFF) |

## In context

| Situation | Input | Action |
|---|---|---|
| In the air | J | Jump kick |
| Running | J | Flying kick |
| Running | L | Bicycle kick |
| An enemy lying ahead (up to 80 px), nobody standing in reach | J | Wrestling elbow drop: Brick steers through the air onto the body |
| An enemy buried in the floor | L | Kick the head off |
| A prop in reach, nobody to hit | J | Pick the prop up |
| Holding a prop | J | Swing it (a chair, stool or bottle: throw it) |
| Holding a prop | L | Throw it |
| Walking into a dazed enemy | (walk) | Grab |
| In a grab | J | Headbutt; the 3rd one throws |
| In a grab | K | Throw |
| In a grab | L | Rip an arm off (it becomes a club) |
| Jumping into a pool lamp | (jump) | Hang on it |
| Hanging from a lamp | A / D | Swing |
| Hanging from a lamp | J / L | Kick |
| Hanging from a lamp | K | Let go |
| Hanging from a lamp | S + J | Rip the lamp down and keep it as a weapon |

## Feel

- **Input buffer:** a press counts for 8 frames, so pressing slightly early still works.
- **Special and dirty move:** J+K and J+L may be up to 3 frames apart and still count as together.
