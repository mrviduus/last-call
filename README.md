# Last Call

A 16-bit-style beat-'em-up in the spirit of Battletoads & Double Dragon. It's 11:59 PM at the OLD LAMP pub, Brick came for one last pint, and at midnight the gang closes the place.

- **Play in the browser:** https://mrviduus.github.io/last-call/
- **Documentation:** [docs/](docs/README.md)
  - [Design](docs/design/README.md): lore, core loop, controls, combat, enemies, environment, art direction. For designers and artists.
  - [Technical](docs/tech/README.md): architecture, tuning, art pipeline, build/test/deploy. For programmers.
- **Credits:** [CREDITS.txt](CREDITS.txt) lists the art sources (all original or CC0).

## Controls

| Key | Action |
|---|---|
| WASD | Move; double-tap A/D to run |
| J | Punch |
| L | Kick |
| K / Space | Jump |
| J+K | Special |
| H | Show all moves |

The full move list is in [Controls](docs/design/03-controls.md).

Built with Unity 6 (6000.6.7f1), WebGL.
